# Domain docs

Compass uses one product context across frontend, backend, data, and infrastructure modules.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant decisions under `docs/adr/` when the directory exists.
- Proceed silently when either location does not yet exist.

## Use the glossary vocabulary

Use domain concepts exactly as defined in `CONTEXT.md` in issue titles, architecture proposals, hypotheses, and tests. A missing concept is a signal to sharpen the product language before spreading a new synonym.

## Flag decision conflicts

When work contradicts an existing architecture decision, identify the decision and explain why reopening it is justified.
